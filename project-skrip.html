Segmentasi Potensi UMKM

Sistem klasifikasi cerdas untuk pemetaan dan perencanaan program pembinaan UMKM yang tepat sasaran di Kabupaten Sampang.

Product Context

Analisis Data UMKM Kabupaten Sampang

Kabupaten Sampang, Jawa Timur memiliki ribuan pelaku Usaha Mikro, Kecil, dan Menengah (UMKM) yang tersebar di berbagai sektor. Heterogenitas karakteristik usaha — dari skala omset jutaan hingga ratusan juta per tahun — menyulitkan perencanaan program pembinaan yang tepat sasaran. Sistem ini dibangun sebagai solusi berbasis data untuk memecahkan masalah tersebut dengan memetakan potensi masing-masing usaha secara otomatis.

Project Overview

Peran Anda (Role)

Data Scientist & Developer — Bertanggung jawab dalam seluruh proses analisis data, mulai dari pemrosesan data, perancangan model Machine Learning, hingga penerapan (deployment) antarmuka dasbor interaktif yang berjalan melalui tunneling.

Teknologi Utama (Tech Stack)

Python Google Colab Ngrok / Grok K-Means XGBoost

Fitur Utama & Cara Kerja Solusi

Aplikasi ini berjalan secara cloud-based menggunakan Google Colab yang diekspos melalui layanan Grok/Ngrok, dan memiliki menu utama interaktif yang mencakup fitur-fitur berikut:

  • Pemrosesan Variabel Input Lengkap: Sistem mampu memproses 8 fitur variabel utama dari data UMKM, seperti Omset usaha per tahun (Rupiah), Total aset usaha (Rupiah), Jumlah karyawan (Tenaga Kerja), dan Kapasitas produksi tahunan.
  • Pemodelan K-Means & Entropy Weighting: Penelitian ini membangun sistem segmentasi berbasis data menggunakan K-Means Clustering yang diperkuat Entropy Weighting.
  • Klasifikasi Hybrid XGBoost: Data diklasifikasikan ulang dengan Hybrid XGBoost untuk meningkatkan akurasi prediksi potensi usaha.
  • Navigasi Dasbor Berurutan: Menu utama memandu pengguna mulai dari proses Upload Data, Eksplorasi Data, Konfigurasi model, eksekusi algoritma, hingga melihat Hasil Analisis dan Download laporan.
  • Pemantauan Status Proses: Terdapat indikator di sisi kiri bawah aplikasi untuk memantau status eksekusi data secara langsung.
