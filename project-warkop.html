Warkop 123: Solusi Digital Antrean & Pemesanan Kafe

Mengatasi antrean yang tidak terkontrol pada warkop atau kafe melalui sistem pemesanan mandiri berbasis web (In Development).

Product Context

Warkop 123 Web App

Warkop 123 dikembangkan untuk menyelesaikan permasalahan klasik di warkop atau kafe lokal, yaitu penumpukan antrean saat memesan menu. Dengan slogan "Just brewed happiness in a cup. Order from your table or take it away. No queue, pay with QRIS", aplikasi ini memungkinkan pelanggan memesan langsung dari meja tanpa harus mengantre panjang.

Project Overview

Peran Sulthon (Role)

Frontend Developer & UI/UX Designer — Bertanggung jawab penuh dalam perancangan antarmuka visual yang segar dan modern, serta membangun interaksi logika sistem menggunakan teknologi web murni.

Teknologi Utama (Tech Stack)

HTML5 CSS3 JavaScript (Vanilla)

Fitur Utama & Cara Kerja Solusi

Berdasarkan pengembangan saat ini, aplikasi ini dilengkapi dengan beberapa fitur fungsional penting:

  • Katalog Kategori Menu Interaktif: Memudahkan pelanggan menyaring pilihan berdasarkan kategori seperti Coffee, Special Tea, Non Coffee, dan Snack.
  • Status Toko Real-Time (Open Now Indicator): Menunjukkan status operasional kafe secara langsung di antarmuka utama.
  • Sistem Status Pesanan (Sudah / Belum): Melacak progres pesanan pelanggan secara transparan untuk meminimalisir miskomunikasi dengan barista atau kasir.
  • Integrasi Payment Gateway / QRIS: Memfasilitasi pembayaran non-tunai instan langsung dari meja pelanggan guna menghilangkan hambatan di kasir.
  • Fitur Pencarian Cepat (Search Menu): Memungkinkan pengguna mencari menu favorit mereka dalam hitungan detik.
